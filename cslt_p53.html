  • & (tham chiếu): không sao chép cả struct (có mảng 101 ký tự) mỗi lần gọi.
  • const: hàm chỉ đọc, không được phép sửa s.

BƯỚC 12

Lưu ý thường gặp & mở rộng

LỖI: QUÊN cin.ignore()

cin >> để lại ký tự xuống dòng. getline gặp nó liền dừng nên tên bị bỏ trống. Thêm cin.ignore() ở giữa.

TEST: KHÔNG AI ĐẠT
Nhap so sinh vien N: 2 ... Van 7 Toan 8 → GPA 7.5 ... Van 8 Toan 8.9 → GPA 8.45 == SINH VIEN GIOI (GPA >= 8.5) == Khong co sinh vien gioi.

8.45 < 8.5 nên không đạt. Luôn thử trường hợp danh sách kết quả rỗng.

MỞ RỘNG: std::sort

Thư viện chuẩn sắp xếp nhanh hơn (O(n log n)). Tự viết Interchange Sort giúp hiểu thuật toán.

VÌ SAO DÙNG MẢNG out[ ] RIÊNG?
  • Danh sách gốc list giữ nguyên thứ tự nhập để dùng cho chức năng khác.
  • Mỗi hàm làm một việc: lọc riêng, sắp xếp riêng, in riêng, nên dễ kiểm tra và tái sử dụng.

Tóm tắt nhanh

struct

Gom id, name, lit, math thành một kiểu. Truy cập bằng dấu .; chuỗi C nhập bằng cin.getline.

Hàm

Truyền Student & để sửa, const Student & để chỉ đọc. Mảng truyền vào hàm luôn dùng chung bộ nhớ.

Thuật toán

Lọc: duyệt và chép phần tử thỏa GPA ≥ 8.5. Interchange Sort: so a[i] với mọi a[j] phía sau, GPA lớn hơn thì đổi chỗ.

Nhiều file

.h khai báo, .cpp định nghĩa, main.cpp điều phối. Biên dịch: g++ main.cpp student.cpp.

LỖI 1–4

Lỗi hay gặp khi nhập dữ liệu

1Dùng cin >> để nhập họ tên

name = "Nguyen" lit = 0 math = 6.9e-310 (rác)

>> dừng ở dấu cách. "Van" bị đọc vào lit → thất bại, cin rơi vào trạng thái lỗi, mọi lệnh nhập sau đều bị bỏ qua.

Sửa: cin.getline(s.name, 101);

2Quên cin.ignore() trước getline

name = "" lit = 0 // tên rỗng, điểm hỏng

Chương trình như "nhảy cóc" qua dòng nhập họ tên.

Sửa: thêm cin.ignore(); ngay sau cin >> s.id;

3Gán chuỗi cho mảng char bằng =

error: incompatible types in assignment of 'const char [14]' to 'char [101]'

Mảng không gán trực tiếp được, khác với std::string.

Sửa: strcpy(s.name, "Nguyen Van An"); (cần <cstring>)

4Lặp quá số phần tử / không kiểm tra N

Sinh vien thu 7: // nhập N = 6 mà bị hỏi 7 người

Nếu N > MAX (ví dụ 150) thì ghi ra ngoài mảng a[100]: lỗi bộ nhớ, có thể crash.

Sửa: dùng i < n và do…while (n <= 0 || n > MAX)
LỖI 5–8

Lỗi về hàm & tham số

5Truyền tham trị khi hàm cần sửa struct

a[0].id, a[0].name = giá trị rác // chưa từng được gán

Nhập xong, bản sao bị hủy khi hàm kết thúc. a[i] trong main không thay đổi.

Sửa: void inputStudent(Student &s)

6N không được trả về main

n = giá trị rác → vòng for chạy sai số lần, có thể crash

Mảng thì luôn được dùng chung, nhưng biến int truyền tham trị chỉ là bản sao.

Sửa: int &n (hoặc hàm return n;)

7Thiếu ngoặc trong công thức GPA

1 1003 Le Minh Chau 9.0 9.4 13.7 ... cả 6 SV đều "giỏi", GPA từ 10.1 đến 13.7

/ ưu tiên hơn +. GPA > 10 là dấu hiệu chắc chắn có lỗi.

Sửa: return (s.lit + s.math) / 2;

8Hàm GPA trả về kiểu int

Chỉ còn 2 SV: Chau (9), Ha (9). An 8.7→8, Dung 8.5→8 bị loại

Phần thập phân bị cắt bỏ khi chuyển sang int.

Sửa: double getGPA(const Student &s)
LỖI 9–12

Lỗi trong lọc & sắp xếp

9Dùng > thay vì >=

Chỉ in 3 SV: Chau 9.2, Ha 9.0, An 8.7 // mất Dung 8.5

Luôn thử dữ liệu nằm đúng biên (GPA = 8.5).

Sửa: if (getGPA(a[i]) >= 8.5)

10Quên tăng k khi chép

Khong co sinh vien gioi. // k vẫn = 0

Mọi SV giỏi đều ghi đè lên out[0], hàm trả về k = 0. Viết out[i] = a[i] cũng sai: mảng out bị "lỗ".

Sửa: out[k++] = a[i];

11Đảo ngược dấu so sánh khi sắp xếp

1 Dung 8.5 2 An 8.7 3 Ha 9.0 4 Chau 9.2 // tăng dần

Đề yêu cầu giảm dần: phần tử phía sau có GPA lớn hơn mới phải đổi lên trước.

Sửa: if (getGPA(a[j]) > getGPA(a[i]))

12Hoán đổi thiếu biến temp

1 1003 Le Minh Chau ... 9.2 2 1003 Le Minh Chau ... 9.2 // trùng, mất An, Dung

Sau lệnh đầu, cả a[i] và a[j] đều là cùng một SV. Phải cất a[i] vào biến tạm trước.

Sửa: Student temp = a[i]; a[i] = a[j]; a[j] = temp;
LỖI 13–16

Lỗi khi tổ chức nhiều file

13Chỉ biên dịch main.cpp

$ g++ main.cpp -o app
undefined reference to `inputList(Student*, int&)'

Linker không tìm thấy thân hàm vì student.cpp không được dịch. Trong IDE: file .cpp chưa được thêm vào project.

Sửa: g++ main.cpp student.cpp -o app

14#include "student.cpp"

multiple definition of `getGPA(Student const&)'

Thân hàm bị dịch 2 lần (trong main.o và student.o).

Sửa: chỉ #include file .h, không bao giờ include file .cpp

15Thiếu include guard

error: redefinition of 'struct Student'
Sửa: bọc header bằng #ifndef STUDENT_H … #endif (hoặc #pragma once)

16Prototype khác định nghĩa

undefined reference to `filterExcellent(Student const*, int, Student*)'

Thiếu const → C++ coi là 2 hàm khác nhau (overload).

Sửa: chép y hệt chữ ký hàm từ file .h sang .cpp
