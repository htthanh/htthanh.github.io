}

Từ khóa extends và đơn kế thừa

TRẢ LỜI NGẮN

Không hợp lệ – Java chỉ cho phép đơn kế thừa class (một class cha). Java cũng không có kiểu kế thừa public/protected/private: mọi kế thừa đều tương đương public inheritance. Đa kế thừa "kiểu" được làm bằng interface.

TRẢ LỜI NGẮN

Dùng super(parameterlist); và nó phải là câu lệnh đầu tiên trong constructor của class con. Code dưới bị lỗi: call to super must be first statement in constructor.
