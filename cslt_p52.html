c) CẤP SỐ CỘNG

Ý tưởng: hiệu 2 số liên tiếp không đổi

array.cpp · isArithmetic
n ≤ 2 luôn là CSC

1 hoặc 2 số thì luôn có công sai. Kiểm tra trước để không đọc a[1] khi n = 1.

Công sai d = a[1] − a[0]

Lấy từ cặp đầu làm "chuẩn".

Từ i = 2: a[i] − a[i−1] phải bằng d

Khác d ở đâu → return false ở đó.

Định nghĩa

a[i] − a[i−1] = d  với mọi i ≥ 1

Tương đương: a[i] = a[0] + i·d

Ví dụ

{2, 5, 8, 11} · d = 3{9, 6, 3} · d = −3
{4, 4, 4} · d = 0{1, 3, 5, 8}
d có thể âm hoặc bằng 0: CSC không nhất thiết tăng.

LƯU Ý

Lỗi thường gặp

✗ TRÀN CHỈ SỐ

So với a[i+1] thì phải dừng ở i < n - 1.

✗ SAI CHỈ SỐ ĐỐI XỨNG

Phần tử cuối là a[n - 1], nên đối xứng của a[i] là a[n - 1 - i].

✗ KẾT LUẬN QUÁ SỚM

return true phải nằm sau vòng lặp. Với {1, 5, 2} code này trả sai true.

✗ QUÊN TRƯỜNG HỢP n NHỎ

Kiểm tra if (n <= 2) return true; trước khi tính công sai.

Tóm tắt nhanh

Tăng dần

Duyệt i = 0..n-2, gặp a[i] > a[i+1] thì false. Hết vòng thì true.

Đối xứng

Duyệt i = 0..n/2-1, so a[i] với a[n-1-i]. Khác thì false.

Cấp số cộng

n ≤ 2 ⇒ true. d = a[1]-a[0], mọi a[i]-a[i-1] phải bằng d.
