01 · PHÂN TÍCH

Đề bài nói gì?

Đầu vào (Input)

  • Hai số nguyên M (số dòng), N (số cột).
  • M × N số nguyên của ma trận, nhập theo từng dòng.
  • Dùng mảng int a[100][100] ⇒ 1 ≤ M, N ≤ 100.

Đầu ra (Output)

  • Ma trận sau khi xoay trái 90° (ngược chiều kim đồng hồ).
  • Kết quả có N dòng, M cột (đổi chỗ kích thước!).

Yêu cầu tổ chức

  • Chia thành các hàm: nhập, in, xoay.
  • Project nhiều file: .h (khai báo) + .cpp (định nghĩa) + main.cpp.

13 · LỖI SAI

Những lỗi sai hay gặp

1. In b sai kích thước

Dùng lại m, n của a khi in b ⇒ thiếu/thừa ô, in ra số rác hoặc số 0.

✗ printMatrix(b, m, n);
✓ printMatrix(b, n, m);

2. Nhầm chiều xoay

Dùng công thức của xoay phải ⇒ ra 4 1 / 5 2 / 6 3.

✗ b[i][j] = a[m-1-j][i];
✓ b[i][j] = a[j][n-1-i];

3. Sai giới hạn vòng lặp

Duyệt b mà để i < m, j < n (giới hạn của a) ⇒ chỉ đúng khi ma trận vuông.

✗ for(i<m) for(j<n) b[i][j]=…
✓ for(i<n) for(j<m) b[i][j]=…

4. Quên kiểm tra M, N

Nhập M = 150 ⇒ ghi ra ngoài mảng 100 × 100, chương trình chạy sai hoặc crash.

✗ cin >> m >> n;
✓ do {cin>>m>>n;} while(m<1||m>MAX||…);

5. Lỗi khai báo tham số

Thiếu số cột ⇒ lỗi biên dịch. Thiếu & ⇒ main không nhận được m, n.

✗ void inputMatrix(int a[][], int m, int n)
✓ void inputMatrix(int a[][MAX], int &m, int &n)

6. Lỗi project nhiều file

Chỉ biên dịch main.cpp ⇒ “undefined reference to rotateLeft”. #include "matrix.cpp" ⇒ “multiple definition”.

✗ g++ main.cpp -o rotate
✓ g++ main.cpp matrix.cpp -o rotate
Thêm: dùng chỉ số từ 1 (i <= n) ⇒ truy cập a[i][n] ngoài vùng có dữ liệu · ghi đè trực tiếp lên a (xem slide sau) · quên endl ⇒ cả ma trận in trên một dòng.

16 · MỞ RỘNG

Mở rộng: các phép xoay khác

Xoay phải 90° ⟳

Kích thước N × M.

b[i][j] = a[m-1-j][i];

Cột đầu (đọc từ dưới lên) → dòng đầu.

Xoay 180°

Kích thước giữ nguyên M × N.

b[i][j] = a[m-1-i][n-1-j];

= xoay trái 2 lần.

Xoay trái k lần

Xoay 4 lần quay về như cũ ⇒ chỉ cần xoay k % 4 lần.

k = k % 4; // 0..3

Sau mỗi lần nhớ đổi chỗ m ↔ n.

TỔNG KẾT

Nhớ gì sau bài này?

Hiểu đề

Xoay trái = ngược chiều kim đồng hồ. Cột cuối → dòng đầu. M × N → N × M.

Công thức

b[i][j] = a[j][n-1-i]
i < n, j < m.

Tổ chức code

.h khai báo, .cpp định nghĩa, main gọi hàm. Biên dịch cả 2 file .cpp.

Tránh lỗi

Dùng mảng b riêng, in b với (n, m), kiểm tra 1 ≤ M, N ≤ 100.

Quy trình giải mọi bài ma trận

  • Vẽ ví dụ nhỏ ra giấy, xem trước/sau.
  • Lập bảng “ô mới ← ô cũ”, tìm quy luật chỉ số.
  • Chạy tay với case thường + case biên (1 × N, N × 1, 1 × 1).
  • Rồi mới code, và test lại bằng chính các case đó.

Bài tập tự luyện

  • Viết thêm hàm rotateRight và rotate180.
  • Nhập k, xoay trái k lần (dùng k % 4).
  • Xoay tại chỗ ma trận vuông bằng chuyển vị + đảo dòng.
  • Viết lại cả project bằng vector.
