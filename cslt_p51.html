BƯỚC 7

isPrime – ý tưởng kiểm tra số nguyên tố

array.cpp

Vì sao chỉ thử d đến √x?

Ước của 36 đi theo cặp: 2×18, 3×12, 4×9, 6×6. Mỗi cặp luôn có một số ≤ 6 = √36. Nếu không có ước nào ≤ √x thì cũng không có ước nào lớn hơn.

① Loại số nhỏ hơn 2

Số âm, 0, 1 → false ngay. Ví dụ -6 dừng ở đây.

② Thử chia d = 2, 3, … khi d·d ≤ x

Gặp một ước x % d == 0 → không nguyên tố, return false.

③ Không tìm thấy ước

Ra khỏi vòng lặp mà chưa return → x là số nguyên tố, return true.

Viết d * d <= x thay vì d <= sqrt(x): không cần thư viện <cmath> và tránh sai số số thực.

MỞ RỘNG 1

Gom 2 hàm đếm bằng con trỏ hàm

countNegative và countPrime giống nhau từng dòng, chỉ khác điều kiện: if (a[i] < 0) và if (isPrime(a[i])).
Ta truyền chính điều kiện đó (một hàm) vào làm tham số.
array.cpp (thêm)
① Viết điều kiện thành hàm

isNegative(int) → bool có cùng “kiểu” với isPrime(int) → bool.

② Tham số con trỏ hàm
bool(*cond)(int)

kiểu trả về · tên con trỏ (ngoặc là bắt buộc) · kiểu tham số

③ Gọi qua con trỏ

cond(a[i]) chạy hàm mà cond đang trỏ tới: lúc là isNegative, lúc là isPrime.

Khai báo thêm trong array.h:
bool isNegative(int x);
int countIf(const int a[], int n, bool (*cond)(int));

main.cpp mới & lưu ý khi dùng con trỏ hàm

Enter N = 3 Element 0 = 2 Element 1 = 3 Element 2 = -6 Negative numbers: 1. Prime numbers: 2.
SAI

countIf(a, n, isPrime()) → gọi hàm luôn, thiếu đối số. Phải truyền tên hàm, không có ().

THÊM TIÊU CHÍ MỚI

Chỉ cần viết thêm 1 hàm bool(int):
bool isEven(int x) { return x % 2 == 0; }
countIf(a, n, isEven) → 2

VIẾT GỌN (C++11)

using Predicate = bool (*)(int);
int countIf(const int a[], int n, Predicate cond);
Lambda không bắt biến cũng dùng được:
countIf(a, n, [](int x){ return x > 0; }) → 2

Tóm tắt nhanh

Nhập mảng

Truyền int &n để hàm trả n về cho main. Mảng luôn được truyền theo địa chỉ.

Biến đếm

count = 0, duyệt mảng, điều kiện đúng thì count++, cuối cùng return count.

Số nguyên tố

x < 2 → false. Thử d từ 2 khi d*d <= x; chia hết → false; hết vòng → true.

Nhiều file

.h chứa prototype + header guard, .cpp chứa thân hàm, main.cpp chỉ gọi hàm.
