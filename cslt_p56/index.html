Đề bài & phân tích đề

Practice 5.6 (nguyên văn)

Write C/C++ program to manipulate matrix
(organize in functions and multiple-file project):
- Enter a matrix M x N of integers.
- Print to screen all elements satisfying its value equals to sum of the remaining elements on its row and column.

Dịch sang tiếng Việt

Viết chương trình xử lý ma trận (chia thành các hàm và project nhiều file):
• Nhập ma trận số nguyên M dòng × N cột.
• In ra mọi phần tử có giá trị bằng tổng các phần tử còn lại trên dòng và cột chứa nó.

MụcPhân tích
Input2 số nguyên M (số dòng), N (số cột); sau đó M×N số nguyên.
OutputCác phần tử thỏa điều kiện (kèm vị trí dòng, cột). Nếu không có: in thông báo.
Ràng buộcDùng int a[100][100] ⇒ 1 ≤ M, N ≤ 100. Phần tử có thể âm, bằng 0.
Từ khóa"remaining" = còn lại ⇒ không tính chính nó. Phần tử a[i][j] nằm ở cả dòng i và cột j ⇒ bỏ nó ra ở cả hai.
Tổ chứcChia hàm: nhập, in, tính tổng, kiểm tra, in kết quả. Nhiều file: matrix.h, matrix.cpp, main.cpp.
Câu hỏi cần tự trả lời trước khi code: “tổng các phần tử còn lại” của ô a[i][j] được tính như thế nào? → slide sau.

05

Ý tưởng: làm “trâu” hay tính trước?

Cách 1 · Với mỗi ô, cộng lại từ đầu

Đứng ở từng ô a[i][j], chạy dọc dòng i và cột j để cộng các ô khác.

Dễ nghĩ, nhưng tổng của dòng i bị tính lại N lần (mỗi ô trên dòng tính 1 lần).

Cách 2 · Tính trước tổng mỗi dòng, mỗi cột

Tính 1 lần: R[i] = tổng dòng i, C[j] = tổng cột j. Sau đó mỗi ô chỉ cần 1 phép so sánh.

Giống tính tổng điểm mỗi lớp 1 lần rồi dùng lại, thay vì cộng lại mỗi khi có người hỏi.

Số phép cộng với ma trận 100 × 100

Cách 1
≈ 1.980.000
Cách 2
≈ 30.000
Cả 2 cách đều đúng. Ta chọn Cách 2 vì nhanh hơn ~66 lần và chia hàm rất tự nhiên: computeRowSums, computeColSums, isSpecial.

Biến đổi công thức điều kiện

conLai = (R[i] − a[i][j]) + (C[j] − a[i][j])
conLai = R[i] + C[j] − 2·a[i][j]
Điều kiện: a[i][j] == R[i] + C[j] − 2·a[i][j]
⇔ 3·a[i][j] == R[i] + C[j]
Kiểm chứng a[0][3] = 9: 3·9 = 27 và R[0] + C[3] = 16 + 11 = 27 ✓

Những lỗi sai hay gặp (1): lỗi logic

① Không trừ chính nó

“Còn lại” = bỏ chính nó. Ô nằm ở cả dòng và cột ⇒ trừ 2 lần. Trừ 1 lần: ví dụ 2×2 sẽ không ra a[0][0] = 2.

a[i][j] == R[i] + C[j] a[i][j] == R[i] + C[j] - a[i][j]
a[i][j] == (R[i]-a[i][j]) + (C[j]-a[i][j])

② Quên gán tổng = 0

Mảng cục bộ chứa giá trị rác. Kết quả sai ngẫu nhiên, mỗi lần chạy một khác.

int rowSum[MAX]; for (i...) for (j...) rowSum[i] += a[i][j];
for (i...) { rowSum[i] = 0; for (j...) rowSum[i] += a[i][j]; }

③ Nhầm chỉ số khi tính cột

Luôn là a[dòng][cột]. Dòng chạy tới m, cột chạy tới n. Sai chỗ này chỉ lộ khi m ≠ n!

for (j=0; j<n; j++) for (i=0; i<n; i++) colSum[j] += a[j][i];
for (j=0; j<n; j++) for (i=0; i<m; i++) colSum[j] += a[i][j];

④ In “không có” sai chỗ

Chỉ biết “không có ô nào” sau khi duyệt hết. Dùng biến đếm count.

for (...) for (...) if (thoa) cout << ...; else cout << "Khong co";
if (thoa) { cout...; count++; } ... if (count == 0) cout << "Khong co";
Thêm: dùng for (i = 1; i <= m; i++) (đếm từ 1) ⇒ bỏ sót dòng 0 và đọc a[m] ngoài vùng dữ liệu · chỉ test ma trận vuông nên không thấy lỗi ③ · return ngay khi gặp ô đầu tiên ⇒ thiếu kết quả (case toàn 0).

Những lỗi sai hay gặp (2): cú pháp C++ & project

⑤ Tham số thiếu số cột

Lỗi biên dịch: declaration of 'a' as multidimensional array must have bounds for all dimensions except the first.

void printMatrix(int a[][], int m, int n);
void printMatrix(int a[][MAX], int m, int n);

⑥ Không kiểm tra M, N

Vượt 100 ⇒ ghi đè bộ nhớ khác, chương trình chạy sai hoặc crash mà không báo lỗi.

cin >> m >> n; // m = 150 ? // ghi a[149][..] → tràn mảng
do { cin >> m; } while (m < 1 || m > MAX);

⑦ Chỉ biên dịch main.cpp

Lỗi link: undefined reference to `inputMatrix(int (*) [100], int&, int&)' — có khai báo nhưng không tìm thấy thân hàm.

g++ main.cpp -o matrix
g++ main.cpp matrix.cpp -o matrix

⑧ #include file .cpp

Thân hàm bị chép vào 2 nơi ⇒ multiple definition of `inputMatrix…'. Tương tự nếu viết thân hàm trong .h.

// main.cpp #include "matrix.cpp"
// main.cpp #include "matrix.h"
Thêm: quên include guard ⇒ khai báo trùng khi .h bị include nhiều lần · viết a[i, j] thay vì a[i][j] · gọi printMatrix(a[][], m, n) (đúng: printMatrix(a, m, n)) · phần tử rất lớn (~109) ⇒ tổng tràn int, nên dùng long long cho rowSum/colSum.

Những điều cần nhớ

Hiểu đề

  • “Còn lại” = bỏ chính nó ở cả dòng và cột
  • conLai = (R[i] − a) + (C[j] − a)
  • ⇔ 3·a == R[i] + C[j]

Giải thuật

  • Tính trước R[], C[] một lần
  • Duyệt mọi ô, so sánh O(1)
  • Biến đếm để in “không có”

Code

  • a[][MAX] khi truyền mảng 2 chiều
  • .h khai báo · .cpp cài đặt · main gọi
  • g++ main.cpp matrix.cpp

Bộ test tự kiểm tra

3×4 ví dụ → 9, 8 · 2×2 [2 1;1 0] → 2
1..9 → không có · toàn 0 → in hết
1×1 [5] → không có · số âm [−2 −1;−1 0] → −2
