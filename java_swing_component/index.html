Quy tắc EDT

Tạo & sửa component chỉ trên EDT (invokeLater). Việc chậm → SwingWorker.

Model ↔ View

JList, JComboBox, JTable chỉ hiển thị; dữ liệu nằm trong model. Sửa model → view tự cập nhật.

View index ≠ model index

Khi bảng sắp xếp/lọc, luôn đổi chỉ số bằng convertRowIndexToModel.
