Vì sao cần function template?

Function template: viết một lần

Ghi nhớ

  • T là tham số kiểu (type parameter): giữ chỗ cho một kiểu dữ liệu.
  • template <class T> và template <typename T> là như nhau.
  • Template chưa phải là hàm, nó là khuôn để compiler sinh ra hàm.

Ví dụ cơ bản: compiler sinh hàm từ template

2010.1

Compiler sinh hàm (instantiation)

Lời gọiT suy raHàm được sinh
findMax(a1, b1)——
findMax(a2, b2)——
template
findMax<T>khuôn
→
int findMax(int, int)
double findMax(double, double)
Có thể ghi rõ kiểu: findMax<int>(a1, b1). Gọi findMax(a1, b2) (int và double) sẽ lỗi vì T không thể vừa là int vừa là double → cần findMax<double>(a1, b2).

4

Sửa lỗi cài đặt nhiều file: 3 cách

Cách 1: include file .cpp

main.cpp thấy luôn định nghĩa → tự sinh hàm khi gọi.

✗ Trái thói quen “chỉ include file .h”, dễ gây nhầm lẫn.

Cách 2: khai báo tường minh

Bắt Func.cpp sinh sẵn hàm cho int và double → linker tìm thấy.

✗ Phải liệt kê trước mọi kiểu sẽ dùng; kiểu mới → sửa Func.cpp.

Cách 3: viết hết trong .h

Bỏ Func.cpp, đặt định nghĩa vào file .h.

✓ Cách thường dùng nhất, thư viện chuẩn (STL) làm như vậy.

Template không vi phạm quy tắc “một định nghĩa” (ODR) khi được include vào nhiều file .cpp: các bản sinh ra giống nhau sẽ được linker gộp lại.

Sử dụng class template: chạy từng bước

61.5
TwoEleClass<int> và TwoEleClass<double> là 2 kiểu khác nhau. Với class template phải ghi rõ <kiểu> (từ C++17 compiler có thể tự suy ra từ đối số constructor).

Lớp được compiler sinh ra

class TwoEleClass<int>int x; int y;
int findMax();
class TwoEleClass<double>double x; double y;
double findMax();

Đối tượng

tTwoEleClass<int>
x5
y6
dTwoEleClass<double>
x1.5
y-2.0

Tổng kết: Template

Ý tưởng

Viết code một lần với tham số kiểu T; compiler sinh hàm / lớp cụ thể cho từng kiểu được dùng.

Nhiều file

Compiler phải thấy định nghĩa lúc sinh code → viết trong .h, hoặc explicit instantiation trong .cpp.

Kiểu tự định nghĩa

Kiểu T phải hỗ trợ mọi phép toán dùng trong template (>, <<…) → nạp chồng toán tử.

Trường hợp đặc biệt

Dùng template <> để viết riêng cho một kiểu, ví dụ char* so sánh bằng strcmp.
