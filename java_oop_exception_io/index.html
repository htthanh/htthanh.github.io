Xung đột default method

Phần 1
💡 Trả lời ngắn

Không biên dịch được: MyClass thừa kế hai default method reset() không liên quan nhau từ Alpha và Beta. Phải override reset() và gọi lại từng bản bằng Alpha.super.reset(), Beta.super.reset().

Lỗi biên dịch (bản gốc)
error: types Alpha and Beta are incompatible; class MyClass inherits unrelated defaults for reset() from types Alpha and Beta
✏️ Sửa: override và gọi cả hai default
  • Cú pháp TênInterface.super.method() chọn đúng cài đặt mặc định của interface cha trực tiếp.
  • Override phải là public, vì method của interface luôn public.
⚖️ So sánh C++C++ có diamond problem thật với dữ liệu: dùng virtual inheritance để chỉ giữ một bản lớp cơ sở, và gọi A::reset() để chọn bản. Interface Java không có trạng thái (field instance), nên chỉ xung đột về hành vi, và trình biên dịch bắt buộc lập trình viên tự giải quyết.
